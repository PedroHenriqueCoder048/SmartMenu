# SmartMenu
## Objetivo
Projeto desenvolvido para por em prática os conhecimento adquiridos nas documentações e vídeos de aulas sobre o CSharp , Razor do .Net e SQLite  desenvolver um sistema simples de auto atendimento do cliente para automatizar a eficiencia o fluxo do serviço.

## Funcionalidade do sistemas
- Cliente
  - Realiza o cadastro
  - Escolhe as opções do cardápio
  - Seleciona a forma de pagamento
  - Acompanha a fila de atendimento pelo painel

- Funcionários
  - Gerencia Produtos
  - gerencia pedidos
  - gerencia usuários
